📖 ASV Bible Verse Lookup

How to use:
  • Web interface: asv.html?ref=Genesis 1 1&format=web
  • Plain text (default): asv.html?ref=Genesis 1 1
  • JSON API format: asv.html?ref=John 3 16&format=json
  • Verse range (same chapter): asv.html?ref=Genesis 1:1 - 1:5&format=web
  • Verse range (cross-chapter): asv.html?ref=Genesis 1:1 - 3:1&format=web
  • Using hash: asv.html#Genesis 1 1 (note: format parameter must be in query string)
